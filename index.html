Push this dashboard to Facebook, TikTok and YouTube. Keys load from your LiveKeys sheet.

Option 1 · OBS (recommended)
Option 2 · Direct from browser

1) In OBS add a Browser Source with this page's URL, size matching whatever format you've picked with the ⇄ button (1080×1350 by default — see ?format= below). 2) In OBS Settings ▸ Stream (or the Multistream plugin) paste the Server + Stream Key below for each platform you want live. OBS does the actual RTMP push — this is the reliable option and works with every platform.

Keys are pulled from Code.gs via a token-protected endpoint — see CFG.KEYS_URL / CFG.KEYS_TOKEN at the top of this file's script. Never expose that URL/token publicly.

Limitation: Facebook, TikTok and YouTube only accept RTMP ingest — browsers cannot send RTMP directly, and none of the three officially accept WebRTC/WHIP from a browser. This option only works if a platform/stream key below has a WHIP URL (e.g. a relay service such as Cloudflare Stream or a self-hosted MediaMTX that re-publishes to RTMP for you). Otherwise, use Option 1.
